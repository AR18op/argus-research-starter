# ARGUS Research Starter

A small public companion to ARGUS, an equities research and paper-trading project.

ARGUS explores conservative execution modeling, data validation, risk controls, and reproducible research. It separates micro-cap circuit research from liquid-equity strategy research.

This starter contains a standalone Python example for calculating a hypothetical position size from a notional cap and planned stop-risk budget. It places no orders and makes no profitability claims.

Run the example with `python position_size.py`.

Private project code, trading records, account information, and credentials are excluded from this repository.
